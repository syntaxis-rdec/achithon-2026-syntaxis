The Threat Landscape
The Flaw: AI Agents Have Too Much Unchecked Authority

1. Direct Tool Invocation

Standard agents receive raw tool call bindings (e.g. read_file, send_email, run_sql). Once the model decides to invoke a tool, execution happens immediately without deterministic interception.

2. System Prompts Fail

Telling an AI "Please do not leak confidential files" is advisory, not defensive. Indirect prompt injection inside untrusted documents overrides instructions with near 100% reliability.

3. Exfiltration via Derived Data

An agent reads a secret financial document, writes an innocuous-sounding summary report, and emails it to an external recipient. Traditional tools lack information flow & provenance tracking.

Zero Authority Architecture
The Solution: Deterministic Out-of-Process Gateway

Core Architectural Invariants

  • Zero Execution Authority: The AI model holds no tool handles. It emits an ActionRequest proposal.
  • Capability Tokens: Tools refuse invocation unless accompanied by a private cryptographic token issued by the gateway.
  • Session Principal Binding: Actor identity is bound by the session registry—not spoofable via LLM parameters.
  • Immutable Provenance: Every derived artifact inherits the supreme confidentiality label of all consulted sources.

Interception & Decision Flow

  • 1. Propose: Agent proposes {actor: 'analyst', tool: 'save_report', sources: ['doc-001']}.
  • 2. Clearance: Gateway validates clearance against principal registry (document text is NEVER opened).
  • 3. Lattice: Dynamically calculates LUB (Least Upper Bound): PUBLIC + CONFIDENTIAL = CONFIDENTIAL.
  • 4. Decision: Emits ALLOWED with token or BLOCKED before tool execution.
  • 5. Ledger: Decision logged in cryptographic SHA-256 Merkle chain.
Provable Security
Three Non-Negotiable Hard Guarantees

1. Document-Blind Authorization

The policy engine checks roles, clearances, and classifications. It never parses document text. An injection saying "Ignore all rules" is mathematically inert—the clearance check blocks execution before the file is even read.

2. Dynamic Label Lattice

Information flow follows a strict security lattice. Derived reports inherit the highest label of all read sources (plus the actor's session read history). Declassification is strictly a human officer action creating a linked copy.

3. Policy Drift Defense

Saved workflows store proposals, not stored permissions. If an admin tightens policies out-of-band on disk while a workflow is paused, resumption immediately halts with RULE-POLICY-DRIFT.

Frontier Defense Additions
Merkle Audit Chains, Canary Traps & Redaction

Cryptographic Merkle Audit Ledger

Every audit entry is hashed with SHA-256 and chained to the previous entry:

entry_hash = SHA256(prev_hash + ts + actor + tool + decision + policy_hash)

Any retroactive database manipulation, row deletion, or log tampering breaks the chain instantly. Verified in real-time on the live dashboard.

Canary Honeytokens & Redaction

  • Canary Traps: High-entropy canary tokens catch prompt extraction and exfiltration.
  • Paraphrase Resistance: 4-gram shingle Jaccard overlap catches obfuscated or summarized canary leakage.
  • Zero-Leak Export: agentgate.export automatically scrubs API keys (sk-, ghp-, Bearer) from audit dumps.
